# 给排水维修手册

## 厨房水槽持续漏水

### 常见原因

1. **角阀连接松动**：角阀与水管接口处密封不严，导致持续渗漏
   - 判断方法：关闭总水阀后观察是否停止，检查角阀接口有无水渍
   - 处理方式：拧紧角阀接口或更换密封圈

2. **连接软管接口异常**：软管老化或接口松动
   - 判断方法：检查软管两端接口是否有水迹
   - 处理方式：更换软管或拧紧接口

3. **排水接口异常**：排水管密封圈损坏或接口松动
   - 判断方法：检查排水管与水槽连接处
   - 处理方式：更换排水密封圈

4. **管道连接异常**：PPR管热熔接头处渗漏
   - 判断方法：检查墙体出水口处
   - 处理方式：需专业水电维修重新热熔连接

### 关键判断依据
- 关闭水龙头后仍漏水 → 角阀或管道连接问题
- 仅使用时漏水 → 水龙头或排水接口问题
- 大量出水 → 可能是管道破裂，需紧急处理

### 建议工种
水电维修

### 紧急等级判断
- 持续滴水不影响使用 → 中
- 持续渗漏可能影响楼下 → 高
- 大量出水 → 紧急

## 卫生间排水缓慢

### 常见原因

1. **地漏堵塞**：地漏滤网积攒头发和杂物
   - 处理方式：清理地漏滤网

2. **排水管堵塞**：管道内积攒污垢或异物
   - 处理方式：使用管道疏通器或化学疏通剂

3. **管道坡度不足**：施工遗留问题
   - 处理方式：需评估是否重新调整管道

### 建议工种
水电维修或管道疏通

---

## 卫生间花洒出水异常

### 常见原因

1. **花洒头堵塞**：水垢积聚
   - 处理方式：浸泡除垢

2. **混水阀故障**：冷热水调节失灵
   - 处理方式：更换混水阀芯

3. **软管破裂**：花洒软管老化
   - 处理方式：更换软管

### 建议工种
水电维修
