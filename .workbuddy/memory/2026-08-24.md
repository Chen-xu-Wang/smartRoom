# 2026-08-24 工作日志

## Smart Room 项目（筑维AI - 一房一码住宅智能运维助手）

### 完成内容
按用户提供的完整方案，从零搭建了前后端分离的完整项目。

**后端 (Python FastAPI + SQLite)**：
- `app/data/houses.json`：3套模拟数字档案（1302/805/503），含MiC模块、给排水/电气/卫浴/空调/门窗设备、管线坐标、保修、维修记录
- `app/data/knowledge/`：4个运维知识库（给排水/电气/空调/综合维修手册）
- `app/services/agent.py`：AI Agent状态机（START→COLLECTING_INFO→INFO_COMPLETE→QUERYING_ARCHIVE→SEARCHING_KB→GENERATING_ORDER→ORDER_PENDING→COMPLETE），关键词NLP提取位置/设备/症状/严重度，追问逻辑
- `app/services/rag.py`：知识库分节检索 + 原因提取
- `app/services/archive.py`：房屋档案/历史/重复维修预警
- `app/api/`：houses/chat/workorders/maintenance 四个路由
- 修复一个SQL别名bug：stats接口 COUNT(*) as total 但代码取 ["count"]

**前端 (Vue3 + Vite + Element Plus)**：
- 居民端：扫码→AI对话报修→工单确认
- 物业端：工单审核面板
- 维修端：任务处理+数据回写
- 构建通过（vite build 无错误）

### 测试
`test_e2e.py` 端到端跑通：报修对话→生成工单→物业审核→维修完成→数据回写→重复维修预警。

### 运行方式（Windows）
- 后端：`backend/venv/Scripts/python.exe -m uvicorn app.main:app --port 8000`
- 前端：managed node `node_modules/vite/bin/vite.js --port 5173`
- 重置数据：`backend/reset_data.py`
